■このゲームについて

 インベーダーゲーム


■起動方法

 フォルダ内の「Kadai2.exe」を実行してください


■基本操作

 Ａ もしくは ↓キー：左移動
 Ｄ もしくは →キー：右移動

 Ｚ もしくは Spaceキー：攻撃・復活

 Spaceキー ：決定

 Escapeキー：戻る・ゲーム終了


■このゲームの独自機能 (!!ここ大事!!)

◇プレイヤー追加機能

・プレイヤー画像を選択できます

・残機が減ったら"Spaceキー"が入力されるまで敵の移動等が停止します

・プレイヤーが移動していない時だけ弾丸を発射できます

・プレイヤーの移動方向に画像が変化するようにしました
